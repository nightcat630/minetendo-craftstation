# 配方表

两套并行配方：

- **工作台配方**：不依赖任何前置模组，装了这个模组就能造。
- **机械动力配方**：装了 [Create](https://modrinth.com/mod/create) 才会出现，用**装配线（Sequenced Assembly）**和**动力合成器（Mechanical Crafting）**，材料更省、产量更高。

所有机械动力配方都带 `neoforge:mod_loaded = create` 条件，**没装 Create 时这些配方不会被加载**，不会报错。

### 装配线（Sequenced Assembly）

需要**装配台（Mechanical Press / Deployer / 传送带）**组成的流水线。
所有装配都以一个**过渡物品**为载体，走完工序后变成成品；按下表顺序摆放工位即可。

#### CRT 电视（载体：铁锭）

```
铁锭 ──压制──> 铁锭 ──安放玻璃板──> 铁锭 ──安放铁板──> 铁锭 ──安放红石──> 铁锭 ──压制──> CRT 电视
```

- 输入：铁锭 ×1
- 工位：压床 → 机械手（玻璃板）→ 机械手（铁板）→ 机械手（红石）→ 压床
- 产出：CRT 电视 ×1（1 轮）

#### SFC 主机（载体：安山合金）

```
安山合金 ──安放橡木板──> ──安放红石──> ──压制──> SFC
```

#### GBA 掌机（载体：安山合金）

```
安山合金 ──安放玻璃板──> ──安放皮革──> ──安放红石──> ──压制──> GBA
```

#### 游戏手柄（载体：安山合金）

```
安山合金 ──安放黑色染料──> ──安放红石──> ──压制──> ──压制──> 游戏手柄
```

## 三、两套配方的取舍

| | 工作台 | 机械动力 |
|---|---|---|
| 前置 | 无 | Create（可选） |
| 原料 | 铁 / 玻璃 / 红石为主 | 铁板 / 黄铜板 / 精密构件 |
| 速度 | 一格一格手搓 | 装配线可自动化量产 |
| 定位 | 单件试玩 | 服务器/整合包量产 |

两套配方**产物相同**，装了 Create 时两套同时可用，玩家自己选路线。
